# Yumemono Archive — Website

Static front-end for the Yumemono 夢物 X community archive. Renders **7,590 posts**,
**1,300 media items**, and **912 members** — all mirrored to durable storage,
spanning **2025 – 2026**.

Live: https://yumemono.xyz · Paired pipeline: https://github.com/hazy2go/x-community-archive

## Stack

- Static HTML/CSS/JS (no framework) served from this repo's root
- Vercel **Node** function at `/api/v/[id].js` that proxies Google Drive video
  downloads so `<video>` can embed them cross-origin (strips Drive's
  `Cross-Origin-Resource-Policy: same-site` + `Content-Disposition`, forwards
  Range headers, sets an explicit `Content-Length`). **Must be Node, not Edge** —
  Edge strips `Content-Length`, which breaks Safari/iOS playback.
- Data baked into `data/archive.json` (all posts + authors + media refs)
  generated by `scripts/export_static.py` from the pipeline's SQLite

## Local development

```bash
cd local
# 1. Generate site/data/*.json from the pipeline SQLite
python3 pipeline/scripts/export_static.py \
  --db data/important-community.sqlite3 --out site/data \
  --drive-map ../data/drive-map.json --tco-map data/tco-map.json \
  --avatars-map ../data/avatars-map.json --local-avatars-dir ../avatars
# 2. Copy the JSON into the served data/ dir, then serve the repo root
```

Raw data (SQLite, drive-map, tco-map, avatars-map) lives under `local/` and is
gitignored. See `local/README.local.md` for the full refresh procedure.

## Media pipeline

Media lives in Drive; the exporter rewrites URLs to two Drive endpoints:

- Images → `https://lh3.googleusercontent.com/d/{FILE_ID}=w1200`
- Videos → `/v/{FILE_ID}` (proxied through the Vercel Node function)

**1,300 / 1,300 media items Drive-hosted.** Avatars: 912 / 912 covered
(866 Drive-mirrored + 46 local fallbacks rescued via unavatar.io, served from
`/avatars/{author_x_id}.{ext}`).

### Video first-frames

Google Drive **stopped serving video thumbnails** (`thumbnail?id=…` → 404 for
all video files), so tiles render a real muted `<video src="/v/{ID}?v=5#t=0.1"
preload="metadata" playsinline>`. The `#t=0.1` media fragment makes the browser
natively paint the first frame; the tile is `pointer-events:none` so clicks open
the full-viewport lightbox. (Image thumbnails still use the Drive endpoint.)

## Link expansion

`tco-map.json` resolves every `t.co` shortlink in captured tweet bodies to its
real destination URL (**1,238 / 1,238 resolved**). The exporter substitutes in
place at build time so the archive survives t.co going dark.
